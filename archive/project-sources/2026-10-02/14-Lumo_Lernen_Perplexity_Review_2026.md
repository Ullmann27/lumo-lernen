# DATEI: 02_PROJEKTUEBERSICHT.md

# Projektübersicht – Lumo Lernen

## Produktidee

**Lumo Lernen** ist eine moderne, sichere und kindgerechte Lern-App für Volksschüler der 1.–2. Klasse. Die App soll wie eine lebendige Lernwelt wirken, nicht wie ein trockenes Aufgabenblatt.

Kernfigur ist **Lumo, der Fuchs aus Gänserndorf**. Lumo begrüßt das Kind, erklärt Aufgaben, motiviert bei Fehlern, vergibt Sterne und begleitet durch Lernpfade.

## Zielgruppe

- Kinder 6–8 Jahre
- Eltern / Erziehungsberechtigte
- später optional Lehrer / Nachhilfe

## App-Struktur

### Start

- Lumo-Begrüßung
- Tagesübersicht
- Lernpfad starten
- Belohnungen
- Elternbereich

### Lernen

- Rubriken: Mathe, Deutsch, Sachunterricht, Logik
- einzelne Aufgaben
- Lumo-Hilfe
- Überraschungstest
- KI-Dialog mit Lumo

### Belohnungen

- Sterne
- XP
- Level
- Trefferquote
- 100+ Gutscheine
- automatische Freischaltung
- Eltern-PIN-Einlösung

### Eltern

- PIN-Bereich
- Lernanalyse
- Noteneingabe
- Fotoanalyse-Demo

### Schutz

- Kinderschutz
- keine Werbung
- keine offenen Chats
- keine öffentlichen Rankings
- Datenschutz-/Barrierefreiheitsbereich

## Bestehende technische Umsetzung

- HTML
- CSS
- JavaScript
- PWA-Grundstruktur
- lokale Speicherung über `localStorage`
- Browser-Sprachausgabe über Web Speech API
- optional Speech Recognition API, falls Android/Chrome verfügbar

## Aktuelle Grenzen

- kein echtes Backend
- keine echte OCR/KI-Fotoanalyse
- kein echter Nutzer-Login
- keine echte sichere Datenbank
- keine professionelle synthetische Fuchsstimme
- keine echte 3D-Engine, sondern CSS-3D-Prototyp
- keine echte Mund-/Lippensynchronisation
- keine validierte Pädagogik-Engine
- keine Store-Compliance-Prüfung

## Ziel der nächsten Version

Die nächste Version soll wie eine hochwertige App nach Stand 2026 wirken:

- echtes modernes 3D-Maskottchen
- lebendige Bewegungen
- Mundbewegung passend zur Stimme
- einfliegende Buchstaben/Zahlen
- Lernwelt mit animierten Inseln
- stärkerer KI-Tutor
- professionelles Eltern-Dashboard
- sicherer Datenaufbau
- echte App-Technologie

# 3D-, Animations- und Stimmen-Briefing – Lumo Lernen 2026

## Ziel

Lumo soll nicht mehr wie eine einfache 2D-Zeichnung wirken, sondern wie eine moderne, lebendige, hochwertige Figur aus einer Premium-Kinder-App.

## Gewünschte Wirkung

- freundlich
- weich
- glaubwürdig
- kindgerecht
- nicht gruselig
- nicht zu realistisch wie ein echtes Tier
- nicht billig-cartoonhaft
- eher hochwertiger 3D-Kinderfilm-/Game-Look

## Figur: Lumo, der Fuchs aus Gänserndorf

### Körper

- 3D- oder 2.5D-Fuchs
- großer Kopf
- weiche runde Formen
- große freundliche Augen
- kurzer Körper
- flauschiger Schweif
- Schal oder Halstuch als Wiedererkennungsmerkmal
- freischaltbare Kleidung / Accessoires

### Emotionen

Lumo braucht mindestens diese Zustände:

1. neutral / idle
2. freundlich begrüßend
3. nachdenklich
4. stolz
5. jubelnd
6. tröstend
7. erklärend
8. überrascht
9. konzentriert
10. müde / ruhiger Modus

### Animationen

#### Idle

- sanftes Atmen
- leichtes Schweben
- gelegentliches Blinzeln
- kleine Kopfbewegung
- Schweif bewegt sich langsam

#### Beim Sprechen

- Mundbewegung
- Kopf leicht mitbewegen
- Augen schauen zum Kind
- kleine Gesten mit Pfoten
- Emotion passt zum Satz

#### Bei richtiger Antwort

- Lumo springt leicht
- Sterne fliegen sanft
- Lumo klatscht
- kurzer fröhlicher Sound

#### Bei falscher Antwort

- kein negativer Ton
- Lumo schaut liebevoll
- hebt eine Pfote
- sagt ruhig: „Fast geschafft“
- keine rote aggressive Animation

#### Bei Gutschein-Freischaltung

- Ticket schwebt herein
- Lumo hält Gutschein hoch
- sanfte Glitzeranimation
- Eltern-PIN wird klar erklärt

## Technologien

Mögliche Ansätze:

### Rive

Gut für:

- interaktive 2.5D-Figur
- State Machines
- kleine Dateigröße
- Mobile Performance
- Flutter/React Native Integration

### Lottie

Gut für:

- fertige Motion-Sequenzen
- Onboarding
- Belohnungen
- Sternanimationen

Nicht ideal für komplexe interaktive Figuren.

### Spine

Gut für:

- 2D-Skelettanimation
- Charakterbewegungen
- Spielelogik

### Three.js / React Three Fiber

Gut für:

- echte Web-3D-Umgebung
- 3D-Figur im Browser
- experimentellen PWA-Prototyp

Risiko:

- Performance
- App-Größe
- Komplexität

### Unity

Gut für:

- sehr hochwertiges 3D
- echte Spielwelt

Risiko:

- schwerer
- größere App
- mehr Entwicklungsaufwand

### Flutter + Rive

Empfehlung für echte App:

- Flutter für Android/Fold/iOS
- Rive für Lumo
- Lottie für Belohnungen
- Firebase/Supabase für Backend
- lokale Datenbank für Offline-Modus

## Mundbewegung / Lip Sync

Mindestlösung:

- Mund öffnet/schließt während Sprachausgabe
- mehrere Mundformen:
  - geschlossen
  - leicht offen
  - breit
  - rund
  - lächeln
  - überrascht

Bessere Lösung:

- Viseme aus TTS generieren
- Audiodatei + Zeitmarken
- Mundbewegung passend zu Silben

Premium-Lösung:

- TTS mit Viseme-Events
- Lumo-State-Machine reagiert auf Satztyp
- Emotion + Mund + Gestik synchron

## Stimme

### Aktuelle Grenze

Der HTML-Prototyp nutzt Android/Chrome Text-to-Speech. Das ist nützlich, aber klingt je nach Gerät unterschiedlich und oft technisch.

### Ziel

- professionelle Kinder-App-Stimme
- warme österreichisch/deutsche Aussprache
- keine Roboterstimme
- klare kurze Sätze
- natürliche Pausen
- freundliche Satzmelodie

### Optionen

1. Professionelle Sprecherin/Sprecher aufnehmen
2. Cloud-TTS mit kindgerechter Stimme
3. On-device TTS, falls hochwertig genug
4. Hybrid: feste Hauptsätze als Audio + dynamische KI-Antworten per TTS
