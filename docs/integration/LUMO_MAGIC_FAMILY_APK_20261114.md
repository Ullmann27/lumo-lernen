# LUMO Build 2020 – Android-Kandidat mit integriertem 3D-Zauber

Quellbasis Flutter PR #491 `01575aafc3f5b9032900bb57520ee65e98d7546c` (Zeichen-/C4-Reparatur, 2020, exakte Lernfachwahl und Play-AAB-Bauweg). Ausschließlich die 2020-Native-Pin-Identität wird auf den neuen überprüfbaren Godot Integrations-Commit `c6bb8921964ff3dc50c31f0b2b9f7273383681fc` aus PR #177 gelegt, um die zuvor getrennten echten 3D-Schatzwegweiser und Sternen-Feedbacks der Lernwerkstatt in einer realen APK verbinden zu können. Alle historischen 1950–2019 Pins unverändert; native Quelle aus einem einzigen unveränderlichen SHA.

Originales 7-Job-Android-Test- und Abnahmeverfahren wird für diesen isolierten PR-Branch ausdrücklich aktiviert, ohne die bisherigen erlaubten Zweige zu deaktivieren. Vorgeschrieben sind ursprüngliche Native-/Dart-/Godot-Regressionsprüfungen, Flutter-Gesamtsuite, Android-Hostkompilierung, tatsächlich signierte ARM64/x86_64-Kandidaten, API35-Tour, 2017→2020 In-place-Upgrade und nachträgliche Original-Beleg- und SHA-Prüfung. Android-API37/Fold7-Performance bleibt gesondert erforderlich. Keine stille Veröffentlichung und kein Main-Merge.

Der PR ist ein Release-Kandidat, erst erfolgreich bestandene Jobs/Originalbilder erlauben eine APK-Übergabe. Andere parallel entwickelte Spielwelt- und Dream-UI-Zweige werden nicht überschrieben.
