Read actual C4 state/geometry and exercise only visible Android controls.
Requires an already installed and normally toured, source-bound candidate on a
disposable emulator. No installation, root request, save injection, IPC
request write or product-state repair is performed here. Desktop fixtures are
accepted only by explicit pure-function test arguments, never by the Android
CLI.
