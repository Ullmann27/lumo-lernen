## Rangfolge

**Originalbild > vorhandenes produktives Lumo-Design > neue technische Skizze.** Keine Layout-Neukonzeption ohne Genehmigung.

## Dateiintegrität

`references/SHA256SUMS` erlaubt die Prüfung aller zehn Originale. Die binären Dateien werden über `.github/workflows/import-lumo-references.yml` per GitHub Actions in denselben Branch eingespielt und durch SHA-256 gegen die im Chat erhaltenen Originale geprüft. Weder ein Workflow-Start noch ein vorhandenes Manifest allein gilt als erfolgreicher Upload; nach dem Import die tatsächlichen Pfade kontrollieren.
