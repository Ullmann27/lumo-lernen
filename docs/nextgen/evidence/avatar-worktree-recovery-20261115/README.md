# Originale aus dem abgeschlossenen Avatar-Arbeitsverzeichnis

Vor dem Entfernen der entbehrlichen Arbeitskopie wurden alle 1.038 unversionierten und ignorierten Dateien bytegenau gesichert. Das Archiv enthält frühere Reviewbelege sowie reproduzierbare Godot-Importdateien. `manifest.json` nennt sämtliche Originalpfade, Größen und SHA-256-Werte; jeder archivierte Inhalt wurde vor dem Aufräumen mit seiner Originaldatei verglichen.

Die versionierten Dateien waren unverändert. Der lokale Commit `14c3f3b15855ac42588320e9b2ef48304b4ad579` und der veröffentlichte native Integrationscommit `ec702dad29def7ea3db6f62f2ead7b8ca6bca2bb` haben denselben Tree `eac5bd3097d561b56fe175f997e57e4283389453`. Der Branch bleibt erhalten. Die bereits integrierten nativen CI-Belege unter `docs/nextgen/evidence/native-ci-05` bleiben maßgeblich.

Dieses Archiv ist eine Sicherung früherer Arbeitsoriginale, keine neue Android-Abnahme. Die endgültige APK muss ihre eigene Quellen-, Artefakt- und Laufzeitprüfung bestehen.
